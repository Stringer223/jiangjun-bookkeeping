# ⚔️ 将军记账

一款运行在 **Windows** 平台的本地记账应用，帮你记录日常每一笔**人民币**花销，通过**两级分类**轻松管理开销。

> 数据完全保存在本地，无需联网、无需注册，安全私密。

## ✨ 功能特性

- 📝 **记一笔**：录入金额、分类、日期、备注
- 📚 **两级分类**：一级大类 → 二级小类；内置 9 大类，预置分类锁定不可改，用户可自由新增 / 重命名 / 删除自建分类
- 📋 **账单列表**：按时间倒序展示，支持按月份、分类筛选，按备注搜索
- 📊 **统计**：本月总支出、各分类占比、近 6 个月趋势
- 💾 **本地存储**：数据保存在本地 JSON 文件，重启不丢失
- 📤 **导出 CSV**：一键导出账单，带 UTF-8 BOM，Excel 打开中文不乱码

## 🛠️ 技术栈

- **Electron 31** — 桌面运行时
- **Vue 3 + TypeScript** — 界面与逻辑
- **Naive UI** — 组件库
- **electron-vite + Vite 5** — 构建工具
- **本地 JSON 文件** — 数据存储

## 📁 目录结构

```
src/
├── main/        # 主进程：窗口、数据存储、IPC
├── preload/     # contextBridge 桥接，暴露 window.api
├── renderer/    # Vue 3 + Naive UI 界面
└── shared/      # 主进程 / 渲染进程共享的类型
```

## 🚀 本地开发

环境要求：**Node.js ≥ 18**（推荐 20）。

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（热更新）
npm run build      # 编译产物到 out/
npm run typecheck  # 类型检查
npm run preview    # 预览编译产物
```

## 📦 打包 Windows 安装包

```bash
npm run package:win
```

安装包产物输出到 `dist/`（如 `将军记账-0.1.0-setup.exe`），双击即可安装。

## 💾 数据存储位置

账单与分类数据保存在本地 JSON 文件（Windows 上位于 `%APPDATA%` 下的应用数据目录 `data.json`）。删除或重装应用前，可先备份该文件。
